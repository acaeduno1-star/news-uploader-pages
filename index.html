news-uploader

유튜브 채널 「뉴스 뒤의 원리」 업로드 도구

news-uploader는 「뉴스 뒤의 원리」 채널 운영자가 직접 제작한 해설 영상을 운영자 본인의 유튜브 채널에 올리고 관리하기 위해 만든 개인용 도구입니다. 운영자가 주제를 고르고 영상을 검토·승인한 경우에만 YouTube Data API로 업로드합니다. 다른 사용자에게 서비스를 제공하지 않습니다.

하는 일: 동영상 업로드 · 제목·설명·썸네일·자막 설정 · 재생목록 추가 · 공개된 영상에 퀴즈 댓글 작성 · 운영자 채널의 통계와 새 댓글 확인(읽기 전용)

사용하는 권한: youtube.upload, youtube.force-ssl, yt-analytics.readonly

이 앱은 YouTube API 서비스를 사용합니다.

개인정보처리방침 · 서비스 약관 · YouTube 서비스 약관 · Google 개인정보처리방침

news-uploader is a personal tool used by the operator of the YouTube channel "뉴스 뒤의 원리" to upload and manage explainer videos they produced on their own channel through YouTube API Services. A video is uploaded only after the operator picks the topic and reviews and approves the video. The tool is not offered to other users.

What it does: uploads videos; sets titles, descriptions, thumbnails and captions; adds videos to playlists; posts a quiz comment when a video goes public; reads the operator's own channel statistics and new comments (read-only).

Scopes used: youtube.upload, youtube.force-ssl, yt-analytics.readonly

This app uses YouTube API Services.
