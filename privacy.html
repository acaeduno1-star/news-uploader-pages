news-uploader 개인정보처리방침

시행일: 2026년 10월 1일 · 개정일: 2026년 10월 3일

1. 목적

news-uploader(이하 "앱")는 유튜브 채널 「뉴스 뒤의 원리」 운영자가 직접 제작한 영상을 운영자 본인의 유튜브 채널에 업로드하고 관리하기 위한 개인용 도구입니다. 일반 사용자에게 제공되지 않으며, 운영자 본인의 Google 계정 하나만 앱에 권한을 부여합니다.

2. YouTube API 서비스 이용

앱은 YouTube API 서비스(YouTube Data API, YouTube Analytics API)를 사용합니다. 앱을 이용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

3. 요청하는 권한과 이용하는 데이터

  • youtube.upload — 운영자 채널에 동영상 업로드
  • youtube.force-ssl — 운영자 채널 영상의 제목·설명·썸네일·자막 설정, 운영자 채널 재생목록에 영상 추가, 운영자 영상에 댓글 작성, 운영자 영상에 달린 공개 댓글 읽기
  • yt-analytics.readonly — 운영자 채널 영상의 조회수·시청 시간 등 통계 읽기(읽기 전용)

운영자 영상에 달린 공개 댓글을 읽을 때 댓글 내용, 작성자 표시 이름, 작성 시각이 함께 전달됩니다. 앱은 이를 운영자에게 새 댓글 요약과 시청자 요청 주제를 보여 주는 데에만 사용합니다. 앱은 시청 기록, 구독 정보, 이메일, 연락처 등 다른 개인정보를 읽거나 수집하지 않습니다.

4. 저장과 보관

인증 토큰, 업로드 결과(영상 ID·링크), 통계, 이미 확인한 댓글의 ID와 확인 시각은 운영자 본인의 PC에만 파일로 저장합니다. 시청자가 댓글로 요청한 주제는 해당 댓글의 일부(최대 200자)와 작성자 표시 이름을 함께 운영자 PC에 보관하며, 30일이 지나면 삭제합니다. 통계는 최신 값으로 다시 받아 갱신합니다.

이 데이터는 다음 경우를 빼고 외부로 보내지 않습니다: (1) 댓글 분류·요약을 위해 댓글 내용을 Google Gemini API로 보냄, (2) 성과·댓글 요약을 운영자 본인의 비공개 텔레그램 대화로 보냄.

5. 제3자 제공

앱은 Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 광고 목적으로 사용하지 않습니다. 앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 권한 철회와 삭제

Google 계정 → 타사 연결(Google 보안 설정 권한 페이지)에서 언제든 앱의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없고, 운영자 PC의 토큰 파일과 앱이 저장한 데이터도 삭제합니다. 삭제 요청은 아래 연락처로 보낼 수 있습니다.

Privacy Policy (English)

Effective: October 1, 2026 · Last updated: October 3, 2026

Purpose. news-uploader is a personal tool used only by the operator of the YouTube channel "뉴스 뒤의 원리" to upload and manage videos they produced on their own channel. It is not offered to the public, and only the operator's own Google account is ever authorized.

YouTube API Services. This app uses YouTube API Services (YouTube Data API and YouTube Analytics API). By using the app you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Scopes and data used.

  • youtube.upload: upload videos to the operator's channel.
  • youtube.force-ssl: set the title, description, thumbnail and captions of the operator's videos, add them to the operator's playlists, post comments on the operator's videos, and read public comments on the operator's videos.
  • yt-analytics.readonly: read view and watch-time statistics for the operator's videos (read-only).

When the app reads public comments on the operator's videos, it receives the comment text, the commenter's display name and the time. These are used only to show the operator a summary of new comments and viewer topic requests. The app does not read or collect watch history, subscriptions, email addresses, contacts or any other personal data.

Storage. OAuth tokens, upload results (video IDs and links), statistics, and the IDs and times of comments already seen are stored only on the operator's own computer. For topics that viewers request in comments, an excerpt of the comment (up to 200 characters) and the commenter's display name are kept on the operator's computer and deleted after 30 days. Statistics are refreshed with current values.

This data is not sent anywhere else, except: (1) comment text is sent to the Google Gemini API to classify and summarize it, and (2) performance and comment summaries are sent to the operator's own private Telegram chat.

Sharing. Google user data is not sold, shared with third parties, or used for advertising. Use of Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and deletion. Access can be revoked at any time at Google security settings → Third-party connections. After access is revoked, the local token file and the data the app stored are deleted. Deletion requests can be sent to the contact below.
