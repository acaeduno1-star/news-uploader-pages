news-uploader 개인정보처리방침

시행일: 2026년 10월 1일

1. 목적

news-uploader(이하 "앱")는 유튜브 채널 「뉴스 뒤의 원리」 운영자가 직접 제작한 영상을 운영자 본인의 유튜브 채널에 업로드하기 위한 개인용 도구입니다. 일반 사용자에게 제공되지 않습니다.

2. 이용하는 Google 사용자 데이터

앱은 Google OAuth로 https://www.googleapis.com/auth/youtube.upload 권한 하나만 요청하며, 이 권한은 운영자 채널에 동영상을 업로드하는 데에만 사용합니다. 앱은 다른 사용자의 개인정보, 시청 기록, 구독 정보, 이메일, 연락처 등을 읽거나 수집하지 않습니다.

3. 저장과 보관

로그인 후 발급되는 인증 토큰은 운영자 본인의 PC에만 파일로 저장되며, 외부 서버로 전송하거나 저장하지 않습니다. 업로드 결과(영상 ID, 링크)도 운영자 PC에만 기록됩니다.

4. 제3자 제공

앱은 Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 광고 목적으로 사용하지 않습니다. 앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회와 삭제

Google 계정 → 타사 연결에서 언제든 앱의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 사용할 수 없으며, 운영자 PC의 토큰 파일도 삭제합니다.

Google user data. The app requests only the youtube.upload scope and uses it only to upload videos to the operator's channel. It does not read or collect any other personal data.

Storage. OAuth tokens and upload results are stored only on the operator's own computer and are never sent to any other server.

Sharing. Google user data is not sold, shared with third parties, or used for advertising. Use of Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation. Access can be revoked anytime at Google Account → Third-party connections; the local token file is then deleted.
